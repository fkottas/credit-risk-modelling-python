# Delivery roadmap

The book is intentionally delivered as reviewable, tested releases rather than one unverified upload.

## Foundation - current pull request

- expanded 76-chapter application-first structure;
- source, copyright, evidence, and dataset-licence policy;
- four interchangeable dataset adapters;
- deterministic synthetic portfolio and teaching defects;
- data-quality, PD, simplified ECL, monitoring, and bounded-agent workflow;
- unit, integration, checksum, and GitHub Actions tests;
- four foundation manuscript chapters.

## Release 2 - data and scoring system

- data contracts, point-in-time joins, cohort/vintage/roll-rate examples;
- EDA and feature engineering across compatible datasets;
- logistic regression diagnostics, scorecards, scaling, ratings, calibration, and cut-offs;
- cost, profit, fairness, reason-code, and reject-inference exercises.

## Release 3 - IRB system

- current Basel/EU source map;
- PD long-run average and rating philosophy;
- LGD workout ledger, cures, incomplete recoveries, downturn and MoC;
- EAD/CCF revolving exposure history;
- RWA calculations, validation, and capital impact.

## Release 4 - IFRS 9 and CECL systems

- longitudinal synthetic portfolio and contractual cash flows;
- lifetime PD term structures, SICR, staging, scenarios, discounting, ECL and overlays;
- CECL vintage, roll-rate, DCF, loss-rate, WARM, forecast and reversion examples;
- accounting reconciliation and validation controls.

## Release 5 - portfolio, decisions, and optimisation

- dependence, concentration, Monte Carlo and Credit VaR;
- stress testing and satellite models with licensed macro data;
- pricing, affordability, RAROC, limits, collections, bandits and safe RL.

## Release 6 - production and governed agents

- model registry, reproducible artefacts, API and batch deployment;
- containers, CI/CD, UAT, shadow runs, rollback, resilience and incident response;
- post-deployment monitoring and redevelopment triggers;
- read-only specialist agents, evidence store, policy gates, human approval, red-team and evaluation suites.

Each release must update the source and dataset registers, add executable examples, pass tests, and enter through a draft pull request.
