# Data Sources

This project uses three types of datasets:

## 1. Public API datasets

These datasets can be loaded directly with Python.

Examples:
- OpenML German Credit Dataset
- UCI German Credit Dataset
- World Bank macroeconomic indicators

## 2. Synthetic datasets

Synthetic datasets are generated for educational purposes.

They include:
- Fraud transactions
- LGD data
- EAD data
- IFRS 9 cohort data
- BNPL and microloan data

Synthetic datasets do not represent real individuals, real companies, or real financial transactions.

## 3. Restricted external datasets

Some datasets may require registration or separate download.

Examples:
- Kaggle datasets
- Mortgage loan performance datasets
- Proprietary institutional datasets

These datasets are not redistributed in this repository.
